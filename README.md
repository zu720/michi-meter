# 🍻 わりかん - 飲み会精算アプリ

飲み会の支払いを記録して、誰が誰にいくら払えばいいかを自動計算する割り勘アプリです。

## 概要

「今日は誰がいくら立て替えた？」「結局ひとりいくら？」を、飲み会のあとにサッと精算するためのツールです。
支払いを記録するだけで、**送金回数が最小になるように精算方法を自動計算**します。1円単位まできっちり合わせるので端数で困りません。

## 特徴

- 👥 **メンバー登録**: 参加者を追加するだけ
- 💴 **支払い記録**: 誰が・いくら・何に払ったかを記録。1次会だけ／飲んだ人だけ、など**対象者を選んで割り勘**も可能
- ⚖️ **傾斜配分**: 「上司は多め・幹事は少なめ」など負担割合の調整に対応（任意）
- 🧮 **精算の最小化**: 各人の差額を計算し、**送金回数が最も少なくなる**精算方法を提示
- 💯 **1円単位で正確**: 最大剰余法で端数を配分し、合計がぴったり一致
- 📋 **結果コピー**: 精算結果をワンタップでコピーして LINE 等に共有
- 💾 **自動保存**: ブラウザの localStorage に自動保存

## 使い方

1. `index.html` をブラウザで開く
2. 参加メンバーを追加
3. 支払いがあるたびに「誰が・いくら・何に」を記録
4. 「精算結果」に、各人の差額と精算方法（○○ → △△ ¥xxx）が自動表示されます

## 精算のしくみ

1. 各支払いを対象メンバーに配分し、**支払った額**と**負担すべき額**を集計
2. 差額（＝支払った額 − 負担額）を計算。プラスは受け取る人、マイナスは支払う人
3. 受け取る人と支払う人を大きい順に突き合わせ、**最小回数の送金**で全員の差額を0にします

## GitHub Pages での公開方法

1. このリポジトリをプッシュ
2. Settings > Pages > Source を `main` ブランチに設定
3. `index.html` が自動的に公開されます

## 技術スタック

- React 18（CDN 版）
- Vanilla CSS
- LocalStorage API

すべて 1 ファイル（`index.html`）で完結。ビルド不要でそのまま動きます。
